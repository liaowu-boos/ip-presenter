# 架构

浏览器工作台负责项目编辑、演讲状态、问题队列、素材展示与音频播放。`frontend/src/core.js` 校验项目及动作；`runtime.js` 管理书签与问答；`qwen-session.js` 管理实时语音会话。

FastAPI 位于 `backend/app.py`，提供同源本地 API 并只挂载 `frontend/`。`backend/qwen_realtime.py` 管理实时提供方连接，其他 `qwen_*` 模块管理发言、播放确认与语音适配。密钥留在后端本机配置中。

输出声音实际完成后才推进讲稿；暂停或打断保留恢复位置。人物嘴部跟随输出音频能量，基础图集只实现简单开合，不能视作准确唇形同步。

视频人物与项目专用实验没有包含在本次公开代码中。

项目 JSON 包含图片 data URL、讲稿、知识卡、人物与背景。持久化在浏览器；“导出项目”用于跨浏览器迁移。后端收到用于问答的文本上下文，而不是完整图片像素。
